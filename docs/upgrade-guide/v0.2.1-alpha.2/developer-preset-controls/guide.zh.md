# Agent 预设需要开启开发者工具

[English](guide.md) | 中文

## 变更

设置 `ui-settings.enabled: false` 后，新会话选择器、会话标题模式标签、Agent 预设设置页和创造入口会隐藏。本地连接会将所有非标准的新任务默认值恢复为标准模式，包括创造和自定义预设。此前创造和自定义默认值及入口仍然可用。已有会话保持原模式。

## 迁移

1. 需要使用预设时，在通用设置中开启**显示代码工作视图**（TP Cowork 中称为**开发者模式**），该操作保存 `ui-settings.enabled: true`。
2. 如果默认值已被重置，进入 **Agent 预设**重新选择。开启开发者工具会恢复入口，但不会恢复之前的默认值。
3. 新建会话并确认其预设。已有会话继续使用记录的预设。
